## 使用注意事项

- 只适用于50度的RKP桥，已使用Paris V3进行测试，前后桥的桥杆高度已配平

## 加工注意事项

- 板材厚度**必须**略微超出5mm，否则无法实现**过盈配合**

- 垫片与腹板配合形成的凹槽处需要被**焊接**，安全起见最好是**全焊焊接**

## 装配注意事项

- 如果滑板板面厚15mm，那么需要20mm、30mm长外六角M5螺丝

- 1~2mm厚，外径10mm，M5垫圈

- 如果情况允许，那么螺丝和垫片也可以买英制标准的

- 先装配滑板桥，后装配斜垫片

## 维护注意事项

- 螺丝松动可以使用开口扳手来拧紧
